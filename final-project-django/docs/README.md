**Актуальный локальный статус — 21.11.2026:** шесть улучшений целостности данных реализованы в основном Django-проекте, миграции `listings.0004` и `bookings.0004` прошли на клоне старой БД и на локальной Homebrew MySQL без потери 130 Listing/257 Booking. Полный набор **91/91 Django/MySQL-тестов PASS**; OpenAPI, миграции и Ruff проверены. В Postman Collection и исходном генераторе присутствуют проверки неизменной `total_price`; **полный новый Postman Runner не выполнен**. Локальный Docker daemon на 21.11 недоступен, поэтому контейнерная миграция и повторный 91-тестовый Compose-прогон **не подтверждены**.

**AWS R25 был технически выполнен 19.11.2026**, EC2 после проверки остановлен с сохранённым MySQL volume. **Новые миграции 21.11 в AWS не устанавливались** и сервер в рамках исправлений не запускался. Результаты 91/91 тестов подтверждены независимо для кода в этом репозитории. Предыдущие доказательства Docker 84/84 и HTTP 60/60 относятся к 18–19 ноября, не к текущей версии кода.
