## Архитектура

EC2 m7i-flex.large, eu-north-1 (Стокгольм), Ubuntu 24.04, Docker Engine
29.10.0 и Compose v5.8.0. Nginx публикует только разрешённые анонимные
GET/HEAD через HTTP 80; SSH ограничен доверенным IPv4/32. Gunicorn
доступен через loopback 18765, MySQL не публикуется. Авторизованные
запросы и пароли передаются только по защищённому SSH-forward.
Конфигурация [AWS Compose](../infra/aws-ec2-r25/compose.aws.yml) и
[инфраструктура Terraform](../infra/aws-ec2-r25/README.md) входят в проект;
состояние Terraform, приватные ключи и секретное окружение не входят.

Следующая проверка AWS предполагает резервное копирование, миграцию
изолированной копии, обновление существующего EC2, защищённую HTTP/JWT
регрессию, Postman и последующий Stop. Новое облачное обновление на 24.11
не заявляется выполненным.
