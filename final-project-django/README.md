# Аренда жилья — Django REST API

Итоговый проект программы **Python Developer**, IT Career Hub,
[LMS №271](https://lms.itcareerhub.de/course/view.php?id=271).
Backend аренды жилья на **Django 5.2 LTS, Django REST Framework,
MySQL 8.4**, с JWT, пятью прикладными модулями и OpenAPI.

## Реализованные возможности

| Модуль | Реализация |
|---|---|
| **Accounts** | Custom User, регистрация, JWT access/refresh/logout, Django Groups Tenant/Landlord, права на уровне объекта, точная проверка пароля |
| **Listings** | Создание, изменение и soft delete; активность; каталог, поиск, фильтры цены, комнат, типа жилья и географии; сортировка и пагинация |
| **Bookings** | PENDING/CONFIRMED/REJECTED/CANCELLED; права участников; отмена до дня заезда; транзакционная защита от подтверждения пересекающихся периодов |
| **Reviews** | Один отзыв с оценкой 1–5 и непустым комментарием после завершённой подтверждённой брони; редактирование собственных отзывов, агрегированный рейтинг |
| **Statistics** | Приватные истории и публичные агрегаты за 90 дней; порог трёх разных авторизованных пользователей для публикации популярного запроса |

## Целостность данных

- Географические справочники City/District, внешние ключи и уникальная пара (город, район). Строковый API проверяет принадлежность района городу. Хранение city и необязательного district в Listing — осознанная избыточность с защитой штатных путей записи; подробности в ER-модели.
- Listing: почтовый индекс из пяти ASCII-цифр, 1–100 комнат, положительная цена, допустимые значения Choices. PATCH/DELETE блокируют актуальную строку до валидации; конфликт блокировки MySQL 1205/1213 даёт HTTP 409 с откатом транзакции.
- Booking: полуоткрытый интервал дат, новая заявка допускает заезд не раньше завтра (Europe/Berlin), пределы 365 ночей и 365 дней горизонта. Пересечения подтверждённых бронирований проверяются под блокировкой Listing. CHECK требует заполненный cancelled_at ровно при CANCELLED.
- Цена total_price фиксируется при создании заявки; дальнейшее изменение тарифа её не меняет. Неизвестные исторические цены остаются NULL.
- Явные verbose_name и verbose_name_plural, локализуемые подписи полей/Choices, неизменные строковые значения API. OpenAPI описывает отдельные запрос и ответ JWT-входа.
- Сбой записи события аналитики не нарушает успешное чтение каталога. Faker-наполнение повторяемо при одинаковом seed и параметрах, включая повторные поиски и просмотры. Очистка событий старше срока хранения выполняется отдельной командой.

## Локальный запуск

Docker Compose использует MySQL 8.4 и Django; на AWS — Gunicorn/Nginx.
Конфигурация задаётся через локальный файл .env на основе
[шаблона](.env.example); реальные секреты не входят в Git.

```bash
docker compose config --quiet
docker compose up -d --build
docker compose ps
python3 infra/smoke_container.py
docker compose --profile test run --build --rm tests
```

При запуске веб-контейнера выполняются миграции. Faker-данные формируются
командой manage.py seed_demo. Сценарий infra/demo_flow.py проверяет
пользовательские операции реальными HTTP-запросами. Подробности:
[Docker](docs/container-run.md) и [демонстрация](presentation/demo-runbook.md).
