## Сценарий защиты (5–10 минут)

1. **Архитектура/БД:** [ER/3NF](../docs/architecture/er-model.md) и [ER-диаграмма](../docs/architecture/er-diagram.mmd); 5 приложений, Custom User, Groups, CHECK/UNIQUE/FK/индексы. Рубрика R01/R26/R29/R30.
2. **Запуск:** [demo-runbook.md](demo-runbook.md) — Compose, миграции, healthcheck, smoke, OpenAPI, изоляция MySQL volume. Рубрика R24; сведения о проверенном 19.11 AWS EC2 R25 есть в каноническом плане; **EC2 сейчас STOPPED**, схема 21.11 и проверенный release `f318e89` применены; публичный AWS HTTP 22/22, защищённый JWT/API-прогон этой версии ещё ожидается.
3. **Работа API:** приватный Postman workspace, контейнерное окружение `18765`, `Demo flow` и отрицательные HTTP-примеры; резервная проверка — `infra/demo_flow.py`. Рубрика R02–R23/R27/R31.
4. **Гарантии и ограничения:** два конкурентных MySQL-теста, запрет двойной подтверждённой брони и отзыва, soft delete без потери истории, незащищённость от прямой SQL-вставки в обход бизнес-сервиса. Рубрика R18–R20/R28/R32.

## Проверенные ответы на «почему именно так?»

- **Не UUID повсюду:** Django BigAutoField достаточен для внутренних PK; реальные права не обеспечиваются секретностью ID.
- **Не одиночный User.role:** стандартные Groups позволяют одновременное членство и отделены от object permissions.
- **Не отдельная Property в MVP:** без реальной идентификации жилья она не исключила бы ложные дубликаты, но усложнила бы модель.
- **Не триггер на MySQL для календаря:** бизнес-операции централизованы и блокируют Listing на сервере; прямой SQL остаётся границей гарантии.
- **Не считать unit-тесты прямым пунктом LMS:** это самостоятельный стандарт качества и доказательство поведения; особенно ценны два конкурентных `TransactionTestCase`.

## Репетиция

При каждом вопросе показываются **короткий ответ → файл/метод → конкретный тест или HTTP-результат → ID рубрики**. На вопрос об AWS: показать **подтверждённый R25 19.11 и обновление 21.11**, обе применённые миграции, 22/22 публичных HTTP и актуальный статус STOPPED. Локальные и изолированные MySQL-тесты являются отдельным доказательством; **не выдавать исторические облачные 68/68 JWT за новый прогон**. AWS EC2 остановлен с сохранёнными EBS/MySQL, поэтому live URL до отдельного разрешённого запуска недоступен. Не изменять данные преподавательского репозитория, не запускать LMS и не публиковать секреты во время защиты.
