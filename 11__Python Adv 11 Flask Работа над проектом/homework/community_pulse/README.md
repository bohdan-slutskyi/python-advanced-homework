# Community Pulse — урок 11

Учебный Flask-проект для практики CRUD-эндпоинтов вопросов и работы со
статистикой ответов. Структура проекта разделяет SQLAlchemy-модели, Pydantic-схемы
и HTTP-роутеры.

В проекте выполнено домашнее задание 6: добавлена поддержка категорий вопросов.
Он создан отдельно в `practice/` и не изменяет LMS-материалы.

## Подготовка и запуск

Из каталога этого проекта:

```bash
uv lock
uv sync --locked
uv run --locked python run.py
```

После запуска приложение доступно по адресу `http://127.0.0.1:5000`.

`models/` отвечает за хранение данных, `schemas/` — за валидацию и формат
данных API, `routers/` — за обработку HTTP-запросов.

## Миграции

В проект подключён Flask-Migrate. Каталог `migrations/` хранит историю изменений
схемы базы данных. После изменения моделей миграции выполняются из корня проекта:

```bash
uv run --locked flask --app run.py db migrate -m "описание изменения"
uv run --locked flask --app run.py db upgrade
```

Для учебного запуска `python run.py` также оставлен автоматический `db.create_all()`.

## Эндпоинты для Postman

### Вопросы

| Метод | URL | Назначение |
|---|---|---|
| `GET` | `/questions/` | получить все вопросы |
| `POST` | `/questions/` | создать вопрос |
| `GET` | `/questions/<id>` | получить вопрос по ID |
| `PUT` | `/questions/<id>` | изменить текст вопроса |
| `DELETE` | `/questions/<id>` | удалить вопрос |

Тело для создания вопроса:

```json
{"text": "Текст нового вопроса", "category_id": 1}
```

Ответ успешного создания вопроса содержит Pydantic-схему `QuestionRead`:

```json
{
  "id": 1,
  "text": "Текст нового вопроса",
  "category_id": 1,
  "category": {"id": 1, "name": "Общество"}
}
```

Тело для изменения вопроса:

```json
{"text": "Обновлённый текст вопроса", "category_id": 1}
```

### Категории

| Метод | URL | Назначение |
|---|---|---|
| `GET` | `/categories/` | получить список категорий |
| `POST` | `/categories/` | создать категорию |
| `GET` | `/categories/<id>` | получить категорию по ID |
| `PUT` | `/categories/<id>` | изменить категорию |
| `DELETE` | `/categories/<id>` | удалить категорию |

Тело для создания или изменения категории:

```json
{"name": "Общество"}
```

### Answer и статистика

| Метод | URL | Назначение |
|---|---|---|
| `GET` | `/answers/` | получить агрегированную статистику |
| `POST` | `/answers/` | добавить Answer и обновить статистику |

Тело для добавления ответа:

```json
{"question_id": 1, "is_agree": true}
```

Ответ успешного создания содержит сохранённую схему `AnswerRead` внутри поля
`answer`.

В POST-запросах Postman тело задаётся через `Body → raw → JSON`.

## Проверяемые статусы

- `200` — успешное чтение, изменение или удаление;
- `201` — создание вопроса, категории или ответа;
- `400` — отсутствуют или некорректны данные JSON;
- `404` — вопрос или категория с указанным ID не найдены.
